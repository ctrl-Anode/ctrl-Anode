## About Me

I'm a full-stack developer who enjoys building **practical, scalable, and maintainable software** — from clean frontend interfaces to the APIs, data models, and deployment pipelines behind them.

My work and learning interests sit at the intersection of:

- **Web development** — component-driven frontends and well-structured backend services
- **Backend engineering** — REST APIs, authentication, data modelling, and system design
- **AI and LLMs** — integrating language models into useful, real-world applications
- **Automation** — reducing repetitive work through scripts, tooling, and containers
- **Open source** — learning in public and contributing to tools I use

I care about readable code, sensible architecture, and shipping things that actually work.
